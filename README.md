# falling_sand

터미널에서 돌아가는 폴링샌드(falling-sand) 물리 샌드박스 게임이다. 모래·물·돌·불·기름·증기·식물 7종 원소에 더해, 식물을 먹고 자라며 번식하는 벌레(BUG)까지 총 8종이 중력·확산·인화·포식 같은 규칙으로 상호작용하는 셀 오토마타를, curses TUI 위에서 실시간으로 그리고 붓으로 칠하며 가지고 놀 수 있다.

## 실행법

```bash
python3 falling_sand.py
```

`~/.local/bin`에 심링크를 걸어두면 터미널에서 `sandgame`(또는 `fallingsand`)으로 바로 실행된다.

터미널은 최소 40열 x 12행 이상이어야 하며, 너무 작으면 크래시 대신 크기를 키워달라는 안내 메시지가 뜬다.

## 조작법

| 키 | 동작 |
|---|---|
| 화살표 / `h` `j` `k` `l` | 브러시 커서 이동 |
| `SPACE` | 그리기 켜기/끄기 토글. 켜져 있으면 커서가 움직이는 대로 계속 그려짐 |
| `1` ~ `7` | 원소 선택: 모래/물/돌/불/기름/증기/식물 (벌레는 숫자키가 아니라 `/` 팔레트에서만) |
| `/` | 원소/브러시 팔레트 열기. 2단 메뉴(왼쪽=원소, 오른쪽=브러시 크기) — `←`/`→`(`h`/`l`)로 열 전환, `↑`/`↓`(`k`/`j`)로 원소 이동(원소 열) 또는 크기 조절(브러시 열, 즉시 반영), `Enter`로 원소 확정+닫기, `Esc` 또는 `/`로 취소. 열려 있는 동안 그리기·커서 이동 등 다른 조작은 무시됨 |
| `e` | 지우개(빈 칸) 선택 |
| `[` / `]` | 브러시 반지름 축소 / 증가 (0~12) |
| `c` | 화면 전체 지우기 |
| `p` | 물리 시뮬레이션 일시정지 / 재개 (정지 중에도 칠하기는 가능) |
| `q` / `ESC` | 종료 |
| 마우스 클릭·드래그 | 지원되는 터미널에서 커서 이동 + 현재 원소로 칠하기 (보너스 기능, 없어도 키보드만으로 전부 동작) |

화면 하단 한 줄에 선택된 원소·브러시 크기·그리기 켜짐 여부·일시정지 여부·FPS와 간단한 힌트가 항상 표시된다.

## 원소와 반응

| 원소 | 특성 |
|---|---|
| 모래 (SAND) | 중력으로 낙하, 막히면 대각선으로. 물·기름보다 무거워 그 안으로 가라앉는다 |
| 물 (WATER) | 아래 → 대각선 → 좌우 순으로 흐르고 퍼진다. 기름보다 무거워 기름을 위로 띄운다 |
| 돌 (STONE) | 불변·불활성 벽. 모든 것을 막는다 |
| 불 (FIRE) | 일정 수명 동안 타오르며 살짝 위로 일렁인다. 인접한 기름·식물·벌레를 즉시 점화시키고, 인접한 물 중 tick당 한 칸만 증기로 바꾸며(그만큼 자기 수명도 줄어든다) 여러 물에 둘러싸여도 한 번에 다 꺼지지 않는다. 수명이 다하면 낮은 확률로 증기가 되거나 대부분 소멸한다. 돌·모래·물 자체는 타지 않는다 |
| 기름 (OIL) | 물처럼 흐르지만 더 가벼워 물 위로 뜬다. 불에 잘 붙는 인화성 물질 |
| 증기 (STEAM) | 위로 상승하며 옅어지다가, 위가 막히거나 돌·식물 같은 차가운 표면에 닿거나 꼭대기에 닿거나 수명이 다하면 낮은 확률로 물로 응결한다(막힘/접촉으로 실패하면 증기로 남아 다음 프레임에 다시 시도 - "천장 비" 순환) |
| 식물 (PLANT) | 낙하하지 않는 고정 원소. 물에 인접하면 낮은 확률로 위쪽을 편애하며 빈 칸으로 서서히 자라나는데, 빈 칸으로 자랄 땐 인접한 물 한 칸을 실제로 마셔 없앤다(물질 보존). 불에 인접하면 인화된다 |
| 벌레 (BUG) | 식물을 먹고 자라며 번식하는 작은 생물. 인접한 식물을 먹어 에너지를 얻고, 에너지가 충분하면 번식하며, 시간이 지나면 배고파 죽는다(에너지 0 이하면 소멸). 물에 3면 이상 둘러싸이면 익사 피해를 입고, 불에 닿으면 타 죽는다. 평소엔 근처 식물 쪽으로, 없으면 배회하며 불을 피해 이동한다. 숫자키가 아니라 `/` 팔레트에서만 고를 수 있다 |

## 자기테스트

curses 화면을 띄우지 않고 물리 로직만 검증하는 헤드리스 모드가 있다.

```bash
python3 falling_sand.py --selftest
```

모래 낙하, 물의 좌우 확산, 불에 인접한 기름의 인화, 다수 원소(벌레 포함)가 섞인 상태에서 여러 스텝을 예외 없이 도는지, 그리고 벌레의 식물 섭취·아사·화염 사망·스텝당 최대 한 칸 이동을 확인하고 마지막 줄에 `SELFTEST PASS` 또는 `SELFTEST FAIL: <이유>`를 출력한다(실패 시 종료 코드도 0이 아니다).

`python3 falling_sand.py --help`는 화면을 띄우지 않고 사용법 요약만 출력한다.

## 의존성

Python 3 표준 라이브러리만 사용한다. 유일하게 눈에 띄는 import는 `curses`이며, pip으로 따로 설치할 패키지는 없다.
